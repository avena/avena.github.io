Editar\\

nano /opt/ltsp/i386/etc/lts.conf

[Default]
LDM_AUTOLOGIN = True@]
todas as maquinas vão ter que estar listadas (abaixo) e vão abrir direto na sessão X - quem não estiver listada não aparece nem a tela do LDM para fazer login.

ou usar:
[@
[Default]
LDM_GUESTLOGIN = True@]
todas vão para tela do LDM com uma opção abaixo - Login as Guest - se maquina estiver listada com um usuário e feito login com este usuário/guest/convidado....ou se pode entrar com sua própria conta.

Como listar terminais\\
[@
[192.168.0.24]             # ip do terminal 
LDM_USERNAME = terminal01  # usuário que vai ser usado no terminal - o usuário tem que existir no servidor
LDM_PASSWORD = 123         # senha do usuário indicado

Depois rodar:\\

ltsp-update-image\\

Cada mudança dentro do lts.conf, rodar depois o ltsp-update-image e aguardar enquanto ele gera nova imagem, ai (re)ligar terminais.
