Caso você tenha um terminal que carrega o ltsp, aparece a tela de login e parece estar tudo ok, mas ao digitar uma letra somente uma vez ela se repete muito mais.

Tipo digita somente uma vez a letra a, mas aparece aaaaaa para controlar isso faça o seguinte.

Abra o nano /etc/dhcp3/dhcpd.conf

[@host ws150 { # escolha um host para o terminal

hardware ethernet 00:08:C7:4B:FC:CD; # mude para o Mac Address da placa de rede do terminal

fixed-address 192.168.20.150; # defina um ip fixo para este terminal.

option option-128 e4:45:74:68:00:00; # não mude essa linha...isso não é um mac

option option-129 "acpi=off"; # evita disparo de letras.

filename "/lts/vmlinuz-2.6.17.3-ltsp-1";

}@]
