Disquete de Boot para diversas placas de rede, com possibilidade de transferir conteudo do disquete para o HD.

Este disquete estava sendo usado no MRP-Itu pelo William, e ao que parece ele vem e foi criado pelo pessoal do Suite Telecentro

Imagem\\

bootdisk_rede.img\\

etherboot_5.4.0\\

eb-net.iso

Gravar\\

cat bootdisk_rede.img > /dev/fd0\\

ou\\

dd if=bootdisk_rede.img of=/dev/fd0\\

Recomendavel usar o dd para gravar a imagem do disco de boot...pois ele mostra se deu erro ou se foi gravado corretamente.\\
